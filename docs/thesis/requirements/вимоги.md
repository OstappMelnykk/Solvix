# Вимоги до магістерської: коротко

Основне джерело: `MasterThesis2023Edited.pdf` (ФПМІ ЛНУ, 2023, 122 «Комп'ютерні науки», ОПП «Інформатика», кафедра інформаційних систем). Групу ПМІМ-22 згадано у зразку титулки, тож це ваш документ. Старіші `ФПМІ-вимоги-до-магістерських-2018.pdf` і `ФПМІ-методичні-вказівки-2024-ОПП-Системний-аналіз.pdf` для звірки.

Правил про ШІ та обсяг у сторінках у цьому документі немає. У розсилці для курсової (травень 2026) було правило: наприкінці «Висновків» вказати інструменти ШІ й посилання на відкритий репозиторій GitHub. Для магістерської уточнити в керівника.

## Структура
1. Титульний аркуш (входить у нумерацію, номер не проставляють)
2. Зміст (з нової сторінки)
3. Перелік умовних позначень, символів, скорочень і термінів (після змісту, з нової сторінки)
4. **Вступ**: стан проблеми, актуальність, мета. 1–5 сторінок, не нумерується
5. **Суть роботи**: розділи 1, 2, 3… (самостійного розділу «Суть» немає). Приклад назв за методичкою: Постановка задачі; Модель даних; Використаний набір технологій; Особливості програмної реалізації; Опис інтерфейсу користувача. Наголос на новизні; довгі докази йдуть у додатки
6. **Висновки**: з нової сторінки, не нумеруються. Оцінка результатів (і негативних) з урахуванням світових тенденцій, галузі використання, наукова й соціальна значущість
7. Рекомендації: з нової сторінки, не нумеруються, необов'язкові
8. **Список використаних джерел**: з нової сторінки, посилання `[1, 5–8]`, ДСТУ 8302:2015
9. Додатки: кожен з нової сторінки

Обов'язкові: титульний аркуш, зміст, вступ, суть, висновки, список джерел.
