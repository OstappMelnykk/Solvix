# Вимоги до магістерської: коротко

Джерело: методичка ФПМІ ЛНУ (2018) і методичні вказівки 2024 (ОПП «Системний аналіз»), обидві в `джерела/`. Для кафедри інформаційних систем окремого документа не знайдено, тож **уточнити в керівника, яка діє**.

## Структура
1. Титульний аркуш (без номера, але входить у нумерацію)
2. Зміст
3. Перелік позначень і скорочень (за потреби)
4. **Вступ** — стан проблеми, актуальність, мета. 1–5 сторінок, не нумерується
5. **Суть роботи** — розділи 1, 2, 3… з підрозділами (1.1, 1.1.1). Наголос на новизні. Довгі доведення йдуть у додатки
6. **Висновки** — з нової сторінки: оцінка результатів (і негативних), де застосувати, значущість
7. Рекомендації — за потреби, з нової сторінки
8. **Список джерел** — з нової сторінки, посилання `[1, 5–8]`, оформлення за ДСТУ 8302:2015
9. Додатки

Обов'язкові: титульний аркуш, зміст, вступ, суть, висновки, список джерел.

## Оформлення
| Що | Вимога |
|---|---|
| Аркуш | А4, один бік |
| Шрифт | Times New Roman 14 |
| Інтервал | 1,5 |
| Абзац | відступ 12,5 мм, вирівнювання за шириною |
| Поля | ліве 25, праве 10, верхнє і нижнє 20 мм |
| Нумерація сторінок | арабські цифри, правий верхній кут, без крапки |
| Заголовки розділів | по центру, ВЕЛИКИМИ, без крапки, без переносів |
| Підрозділи | з абзацного відступу, перша велика, решта малі |
| Рисунки | «Рисунок 2.1 – Назва» під рисунком; посилання в тексті обов'язкове |
| Таблиці | нумерація в межах розділу, посилання в тексті |
| Не нумеруються | зміст, перелік, вступ, висновки, рекомендації, список джерел |

## Захист
- Доповідь до **10 хв**, вільно, не зачитувати
- Презентація: **6–10** наочних матеріалів, показати програму
- Оцінює ДЕК: «відмінно / добре / задовільно / незадовільно»
- Враховують: новизну, практичне значення, самостійність, відгук керівника, рецензію, виступ і відповіді

## Не допустять до захисту, якщо
- порушені строки подання або тема не затверджена наказом
- структура не відповідає вимогам
- недбале оформлення
- плагіат (перевіряє кафедра перед допуском)

## Чого в документах немає
- Обсягу в сторінках (для плану закладено 60–80, це припущення)
- Мінімального відсотка оригінальності
