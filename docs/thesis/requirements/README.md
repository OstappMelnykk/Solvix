# requirements: вимоги до магістерської

- `MasterThesis2023Edited.pdf`: **головні вимоги**: методичні вказівки до виконання магістерських робіт, спеціальність 122 Комп'ютерні науки, ОПП «Інформатика», Львів 2023 (28 стор., рекомендовано кафедрою інформаційних систем). Джерело: https://ami.lnu.edu.ua/wp-content/uploads/2023/12/MasterThesis2023Edited.pdf
- `вимоги.md`: скорочені вимоги на одному екрані (структура, оформлення, захист).
- `ФПМІ-вимоги-до-магістерських-2018.pdf`: основні вимоги факультету (структура, оформлення), загальні, не для нашої ОПП.
- `ФПМІ-методичні-вказівки-2024-ОПП-Системний-аналіз.pdf`: вказівки 2024 року, але для ОПП «Системний аналіз», не для нашої кафедри.
