# thesis: магістерська

Усе про магістерську роботу.

- `Магістерська-робота.docx`: текст роботи (титулка й порожній каркас розділів).
- `requirements/`: вимоги (методички факультету, `вимоги.md`).
- `presentation/`: матеріали презентації.
- `animations/`: анімації до захисту.
- `sources/`: літературу й чужі роботи для порівняння (поки порожньо).
- `helpers/`: допоміжні файли (для Claude, поки порожньо).
