# Якість сітки: база джерел і рішення

Машинно-читана база — `sources.json` (id джерела, URL, що сказано, числа, статус перевірки). Тут — що з цього випливає
для Solvix і що ще треба дослідити. Правило: **числа без прочитаного джерела не заносимо**; якщо відтворено з пам'яті —
статус `memory`, і це пишемо в інтерфейсі.

## Мета

Для криволінійних гексаедрів (20-вузловий ізопараметричний елемент, ребра — параболи через серединний вузол) мати
**один точний критерій «приймається / ні»**, підкріплений реальною документацією, а не власними здогадками.
Порівняння з іншими інструментами — окремий, ізольований перегляд (лише візуал), який нічого не вирішує.

## Що знайдено про саме 20-вузлові цеглини

Єдине прочитане джерело, яке прямо описує перевірки форми для 20-вузлової цеглини з серединними вузлами —
**ANSYS Mechanical APDL Theory Reference, §12.1** (`ansys-apdl-shape`):

| Міра | Як рахується | Попередження | Помилка |
|---|---|---|---|
| Jacobian ratio | max/min визначника якобіана у **20 вузлах і центроїді**; різні знаки → −100 | > 30 | > 1000 (або −100) |
| Aspect ratio | по 6 граням і 3 перерізах, кутові вузли | > 20 | > 10⁶ |
| Parallel deviation | кут між протилежними ребрами, грані й перерізи, серединні вузли ігноруються | > 100° | > 170° |
| Max corner angle | найбільший кут грані/перерізу, кутові вузли | > 165° | > 179.9° |
| Warping factor | різниця висот / √(проєктована площа), 6 граней | > 0.2 | > 0.4 |

Це і є основа критерію Solvix (див. «Рішення» нижче).

## Що кажуть інші інструменти (лише для перегляду)

| Інструмент | Що і які межі | Джерело (id) | Статус |
|---|---|---|---|
| Abaqus/CAE | кут грані 10°–160°, aspect ratio ≤ 10 (попередження за замовчуванням, гексаедри) | `abaqus-verify-mesh` | read |
| Cubit/Verdict | scaled Jacobian ≥ 0.5, aspect ≤ 4, skew ≤ 0.5, taper ≤ 0.4, stretch ≥ 0.25, diagonal ≥ 0.65, condition ≤ 8, shear ≥ 0.3, shape ≥ 0.3 | `cubit-hex-metrics` | read (межі); формули — memory |
| Altair HyperMesh | aspect ≤ 5 («рідко більше»), Jacobian у точках Гауса ≥ 0.7, warpage ≤ 5° | `altair-element-quality` | read |
| ANSYS (CFD, skewness) | шкала 0–1: 0.25 / 0.5 / 0.75 | `ansys-turbogrid-limits` | read; формулу для гексаедрів не знайдено |

Усі вони, крім ANSYS APDL, оцінюють **лінійний** гексаедр (8 кутових вузлів): кривизна ребер ними не враховується.

## Рішення (журнал)

- **2026-10-11.** Критерієм Solvix для «приймається / ні» стають п'ять мір ANSYS APDL для 20-вузлової цеглини
  (таблиця вище): ліміт-«попередження» = «не приймається», ліміт-«помилка» = розрахунок неможливий. Підстава: єдине
  прочитане джерело, що описує саме 20-вузлові цеглини з серединними вузлами; числа з документації.
- Інші інструменти — окремий перегляд, ізольований від рішення.
- Власні «правила» без джерела (0.7 / 0.4 / 0.15 для scaled Jacobian, поріг 3 із 5 стандартів тощо) — **знімаються**.

## Власні обчислення (не джерела — перевірки нашої реалізації)

- **Warping factor** за відтворенням з тексту ANSYS: верхня грань одиничного куба, повернута на 22.5° → **0.197**, на 45° →
  **0.398**; документація каже «близько 0.2» і «близько 0.4» (тест `Twisting_the_top_face_warps…`). Реалізація узгоджується.
- **Jacobian ratio vs положення серединного вузла** (ребро довжини 1, вузол зсунуто від кута на `s`): s=0.5 → 1; 0.45 → 1.5;
  0.4 → 2.33; 0.35 → 4; 0.3 → 9; **s=0.25 (чверть ребра) → якобіан у куті = 0 (−100)**; далі «вивернуто». Тобто серединний
  вузол має лишатись у **середній половині ребра (0.25…0.75)**, а ліміт ANSYS 30 досягається приблизно при s≈0.28.
  Це наш розрахунок за формулами форми, а не цитата з документа; співпадає з відомим фактом про сингулярність чвертьточки.

## Не знайдено / треба дослідити

1. Числове обмеження на зсув серединного вузла гексаедра («середня третина» тощо) — для тетраедрів є робота
   про допустиму область, для гексаедрів не знайдено.
2. Поріг якобіана у точках Гауса саме для 20-вузлових гексаедрів (Gmsh, Code_Aster, CalculiX, Nastran) — шукати в їхніх
   посібниках; ANSYS для цеглин бере вузли, не точки Гауса.
3. Двогранні кути гексаедрів — відкритих меж не знайдено.
4. Верифікація формул Verdict (taper, shear, shape, condition, осі в центрі) за PDF або вихідним кодом; повідомлено про
   розбіжності посібника з кодом (`vtk-verdict-issue`).
5. Робота про точну валідність криволінійних елементів (границі якобіана по всьому елементу, `gmsh-curvilinear`,
   `johnen-hex-validity`) — прочитати повністю: наш критерій перевіряє лише вузли й центроїд.
6. Дослідження залежності похибки МСЕ від спотворення 20-вузлових гексаедрів (числові експерименти) — знайти й занести
   як еталон, щоб межі мали не лише «довідкове», а й кількісне підґрунтя.
7. Реконструкція `aspect ratio` ANSYS: формул у документі немає (картинки); у коді побудову відтворено з тексту.

## Як додавати джерело

Запис у `sources.json` з полями `id, title, url, kind, status, applies_to, key_points, numbers, caveats`. Якщо число
взято з прочитаного тексту — `status: "read"`; з уривка пошуку — `snippet`; відтворено без відкриття — `memory`.
