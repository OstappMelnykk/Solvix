# project: документація Solvix

Усе, що створено під час розробки поточного проєкту.

- `guides/`: як працювати: `RUNNING` (запуск), `BRANCHING` (git flow), `EDITOR_SHORTCUTS` (керування редактором).
- `architecture/`: як влаштовано: `BACKEND_ARCHITECTURE`, `FRONTEND_ARCHITECTURE`, `ISOPARAMETRIC` (вузли й функції форми), `GEOMETRY_RULES` (правила геометрії).
- `planning/`: що робимо: `ROADMAP`, `FIX_LIST`, `IDEAS`, `REVIEW`.
- `algorithms/`: алгоритм локального згущення (`ALGORITHM`, `PROBLEMS`).
- `research/`: дослідження (вимірювання й експерименти).
