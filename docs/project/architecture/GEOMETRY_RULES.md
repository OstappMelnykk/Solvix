# Правила геометрії (Solvix)

Цей файл — єдине джерело істини для правил побудови геометрії з кубиків (гексаедрів) і їхнього локального згущення. Кожне правило має унікальний номер (R1, R2, …), до якого прив'язані тест-кейси. Документ доповнюється поступово, у міру уточнення вимог.

Статус: чернетка, узгоджено з користувачем 2026-07-30.

---

## 1. Означення (Glossary)

- **Кубик (гексаедр)** — базовий будівельний елемент геометрії, шестигранник (аналог блоку в Майнкрафті).
- **Грань** — одна з 6 плоских сторін кубика.
- **Сусідство по грані** — два кубики вважаються сусідніми, якщо вони стикаються цілою гранню (спільна грань). *(Примітка: у майбутньому можливі також сусідства по ребру чи по вершині — це окреме технічне рішення, яке буде розглянуто пізніше й додано до цього документа окремим правилом. Поки що воно НЕ враховується.)*
- **Геометрія** — множина всіх кубиків, розміщених користувачем у сцені на даний момент.
- **Зв'язна геометрія** — геометрія, у якій від будь-якого кубика можна дістатися до будь-якого іншого кубика, рухаючись лише через ланцюжок сусідств по грані.
- **Порожня сцена** — стан, у якому кубиків немає взагалі (0 кубиків).

---

## 2. Правила (Rules)

### R1 — Геометрія завжди єдина і зв'язна
У будь-який момент часу вся розміщена геометрія має бути **одна зв'язна група**. Не може існувати одночасно дві (або більше) групи кубиків, між якими немає жодного шляху через сусідство по грані.

- Розмістити новий кубик дозволено, лише якщо він межує гранню хоча б з одним уже існуючим кубиком — **або** якщо сцена порожня (перший кубик).
- Спроба розмістити кубик "у повітрі", не торкаючись гранню жодного існуючого кубика, — заборонена.

### R2 — Заборонено видалення, що розриває геометрію
Якщо видалення кубика призведе до того, що геометрія розпадеться на дві або більше незв'язаних частин, така операція видалення **забороняється**. Система відхиляє дію і повідомляє користувача.

- Видалення дозволене, тільки якщо після нього решта кубиків і надалі утворює одну зв'язну групу (або решта кубиків — 0 чи 1 кубик).

## 3. Тест-кейси (Test cases)

### R1 — зв'язність при розміщенні

| ID | Сценарій | Очікуваний результат |
|----|----------|----------------------|
| R1-T1 | Сцена порожня, користувач розміщує перший кубик | Дозволено |
| R1-T2 | Є один кубик A, користувач розміщує кубик B впритул гранню до A | Дозволено, геометрія лишається зв'язною (A-B) |
| R1-T3 | Є кубик A, користувач намагається розмістити кубик B на відстані від A (без спільної грані) | Заборонено |
| R1-T4 | Є ланцюжок A-B-C-D (кожен сусід по грані з наступним) | Перевірка зв'язності: від A є шлях до D через B, C — успішно |
| R1-T5 | Є кубик A, користувач розміщує кубик B, що торкається A лише ребром або вершиною (без спільної грані) | Заборонено (не вважається сусідством) |

### R2 — заборона розриву при видаленні

| ID | Сценарій | Очікуваний результат |
|----|----------|----------------------|
| R2-T1 | Ланцюжок A-B-C, видаляється кінцевий кубик C ("листок") | Дозволено, лишається зв'язна пара A-B |
| R2-T2 | Ланцюжок A-B-C, видаляється середній кубик B ("міст") | Заборонено — видалення розділило б геометрію на A і C окремо |
| R2-T3 | У сцені лишився один кубик A, користувач видаляє його | Дозволено, сцена стає порожньою (0 кубиків) |
| R2-T4 | Розгалужена геометрія (A з'єднаний з B і з C, B і C між собою не з'єднані напряму), видаляється A | Заборонено — B і C залишились би без зв'язку між собою |

## 4. Чек-лист (перед релізом / рев'ю коду)

- [ ] Перевірка сусідства реалізована **тільки** через спільну грань (R1)
- [ ] Розміщення кубика без сусідньої грані заблоковано, окрім випадку порожньої сцени (R1)
- [ ] Перед видаленням кожного кубика виконується перевірка зв'язності решти геометрії (R2)
- [ ] Заборонена дія супроводжується зрозумілим повідомленням користувачу (не просто мовчазна відмова)
- [ ] Усі тест-кейси з розділу 3 покриті автоматичними тестами
- [ ] Дотик лише по ребру/вершині (без спільної грані) коректно НЕ трактується як сусідство

## 5. Відкриті питання (буде уточнено пізніше)

- Чи і коли враховувати сусідство по ребру/вершині (окрім базового по грані) — технічне рішення, наразі відкладено.
- Правила для локального згущення (розбиття кубика на менші) та їхній вплив на зв'язність — буде додано окремим розділом.
