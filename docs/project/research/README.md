# research: дослідження

Кожне дослідження в окремій папці з номером і короткою назвою. У кожній `README.md` розповідає, про що воно.

| Папка | Про що |
|---|---|
| `01-refinement/` | Згущення гексаедральної сітки в 3D: що не вийшло, вимірювання |
| `02-quality/` | Критерій якості сітки й база джерел |
| `03-smoothing/` | Згладжування Лапласівкою в 3D зі збереженням густини |

`04-smoothing-sota` (огляд найкращих методів згладжування й експерименти) лежить у гілці `feature/smoothing-research`, у `dev` його поки немає.
