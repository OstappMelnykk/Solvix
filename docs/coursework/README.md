# coursework: курсова

Усе про курсову роботу.

| Файл | Опис |
|---|---|
| `coursework.pdf` | Готовий текст курсової «CAD-редактор для моделювання гексаедральних сіток з алгоритмом локального згущення», найновіша збірка, 52 стор. Три розділи, на які спиратиметься магістерська. Джерело: `~/Desktop/MASTER/Курсова` |
| `coursework.docx` | Та сама курсова у Word, трохи старіша версія (відповідає 51-сторінковому PDF). Зручна для копіювання тексту. Джерело: Downloads |

Дублі (`OM.pdf` у Solution2, `compiled/main.pdf`, `OM (1).pdf`) не беремо: це старіша збірка тексту.

- `presentation/`: презентація курсової.
- `reusable/`: що з курсової можна взяти в магістерську.
- `helpers/`: tex, чернетки, зображення.
