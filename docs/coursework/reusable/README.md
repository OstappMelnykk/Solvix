# reusable: з курсової в магістерську

Матеріали зі старого проєкту (`~/Desktop/Vovk/MastersDegreeProject/docs`), на яких трималася курсова й які знадобляться в магістерській. Відібрано лише те, чого в Solvix немає.

| Файл | Опис |
|---|---|
| `refinement-3d-algorithm-theory.md` | Формальний опис 3D-алгоритму 2-refinement за статтею Owen et al.: основні поняття, нумерація вузлів, шари і проходи, Algorithm 1, Enumerate, маркування вузлів, шаблони, Expand, проходи J і K, умови §4.9. Основа для розділу про алгоритм. У Solvix є лише короткий `project/algorithms/ALGORITHM.md` |
| `mesh-data-structure-face-slot.md` | Проєктування структури даних сітки Compact Face-Slot: вимоги, порівняння альтернатив, ядрові сутності, нумерація вузлів гексаедра, 12 ребер і Q2-вузли, батько-дитина, інваріант конформності, undo/redo, експорт C3D20, схема PostgreSQL. Face-slot використовується і в Solvix (`HexFace.cs`), а обґрунтування вибору є лише тут |
| `old-spec-useful-requirements.md` | Наш витяг зі старого `ТЗ.md`: вимоги до алгоритму (A1–A16), пороги якості, покроковий режим і ідея кроків назад (snapshot + події), quality guard згладжування, режими Editing/Refined, експорт (Gmsh, VTK, Abaqus, JSON), чотири корисні ідеї. Решта ТЗ застаріла |
