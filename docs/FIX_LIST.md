## Закріплення («заморожування») геометрії та солвера
Щоб ніщо не зламалось непомітно, до кожного етапу фіксуємо **еталонний набір**:
1. **Геометрія**: `Solvix.Mesh.Tests` (133) + «золоті» знімки `HexMeshState` для шаблонів (JSON у репозиторії); зміна знімка — свідомий коміт.
2. **Солвер**: patch-тест, Ляме (труба), послідовні пружини, енергетичні тести елемента, + F7–F9 як регресійний набір з допусками.
3. **Контракт**: версія API (F19) і схема збереженого проєкту (F15) з міграціями.
Правило: PR, що змінює ці еталони, мусить пояснити чому.
