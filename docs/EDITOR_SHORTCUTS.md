# Ручний редактор сітки — керування

Вкладки **Real World** (вузли рухаються) та **Ideal World** (ті самі куби на цілих позиціях, вузли фіксовані).

| Дія | Як |
|---|---|
| Вибрати грань | клік по грані |
| Вибрати куб | **Shift + клік** по грані куба (перший вибраний — основа, другий приєднується до нього) |
| Вибрати вузол | клік по точці (у Real World з'являються стрілки — тягніть мишею) |
| Зняти виділення | `Esc` або клік по порожньому місцю |
| Перший куб | `N` (коли сітка порожня) |
| Додати куб на вибрану грань | `A` |
| Зробити два куби сусідами | вибрати 2 куби (Shift+клік) → `L` |
| Поміняти місцями основу й приєднуваний | `S` |
| Розірвати сусідство | вибрати 2 куби → `U` |
| Видалити куб | `Delete` / `Backspace` (вибраний куб, або куб вибраної грані) |
| Скасувати / повернути | `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` або `Ctrl+Y` |
| Зсунути вибраний вузол (Real World) | `←` `→` — X, `↑` `↓` — Z, `PageUp` `PageDown` — Y; `Shift` — ×10 (крок задається в панелі) |

Клавіші не діють, поки курсор у полі вводу. Те саме, що шорткати, робить панель праворуч (кнопки показують свій шорткат).

Другий куб «підлаштовується» під перший: його грань підтягується до грані основи (опція в панелі). Видалення відхиляється, якщо тіло розпадеться на частини.

## Режим «6 сторін» (кнопка на панелі «Вид» над сценою)

- Кнопка **⤢** на виді (або подвійний клік по ньому) робить його **основним**: він збільшується, решта 5 стають смужкою праворуч. **⤡** повертає сітку з 6 видів.
- В основному виді (лише з Real World) вузол можна **тягнути мишею**: він рухається тільки в площині цього виду, третя координата не змінюється. `Shift` — рух по одній осі. Знизу видно координати вузла наживо; після відпускання вони зберігаються на сервері.
- Порожнє місце тягнеться (зсув виду), колесо — масштаб, **⟲** — відцентрувати.

## Почати спочатку

У панелі «Редактор сітки», внизу: **«Почати спочатку (вся сесія)»** → підтвердження → вкладка замінюється новою порожньою сесією (нові куби, порожня історія, без STL, камера за замовчуванням). Стара сесія видаляється й на сервері. **«Очистити сітку»** прибирає лише куби і її можна скасувати (`Ctrl/Cmd+Z`). **«Скинути все»** угорі прибирає всі сесії одразу.


## Конструктор (клавіша `C`)

Окреме вікно з двома режимами:

- **Один куб** — чотири види (спереду / збоку / зверху — вузол тягнеться в площині виду, `Shift` фіксує вісь; 3D — обертання), параметри (довжина, висота, ширина, звуження, зсув), бібліотека форм, таблиця 20 вузлів. «Додати на сцену» ставить куб першим або підганяє під вибрану вільну грань.
- **Шаблони тіл** — типові фігури: прямі (брус, коробка), циліндричні (циліндр/конус, труба), кулі (куля/еліпсоїд, порожня куля, купол), кільця (тор, пластина з отвором), профілі (L, T, U, хрест, сходи). Тип фігури фіксує розкладку комірок в ідеальному світі (труба — замкнений цикл навколо діри), параметри (радіуси, довжина, стінка, кількість кубів по колу/вздовж) лише змінюють розмір. Тіло додається окремою частиною поруч із наявним, без зв'язку з ним, одним кроком undo.

Закруглення: кожен із 20 вузлів куба — образ своєї ідеальної точки, тож крива поверхня несеться справжніми вузлами. Кути ґратки, де дві (або три) грані куба лежать на круглій поверхні, мали б нульовий якобіан; шаблон трохи виштовхує вузли на цих ребрах назовні (найслабший варіант, що не псує жодного куба) — поверхня там має ледь помітний злам. `Solvix.Mesh/HexTemplates.cs`, `Fit`.
