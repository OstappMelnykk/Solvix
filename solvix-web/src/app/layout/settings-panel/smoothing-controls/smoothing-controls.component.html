Згладжування (Лапласівка, 3D)
Вирівнює вершини. Усі параметри ваші. Внутрішні вершини є лише в тілі від 3×3×3 кубів; для тонкого тіла вмикайте поверхню. Можна скасувати (Ctrl+Z).
Вільних вершин: {{ r.free }} із {{ r.corners }} (решта на поверхні, їх без галочки поверхні не чіпаю)
Поганих елементів у кубах з вільною вершиною: {{ r.badReachable }} із {{ r.bad }}
Усі погані елементи в кубах без вільних вершин: без поверхні згладжування їх не змінить. Увімкніть «Згладжувати й поверхню» і піднімайте кут гребеня.
