# Refinement2D web

A page to look at the 2D local refinement (three.js, Vite, TypeScript). It needs the API running:

```
dotnet run --project ../Refinement2D.Api        # http://localhost:5190  (or run Refinement2D.Api from Rider)
npm install
npm run dev                                      # http://localhost:5173, /api is proxied to the API
```
